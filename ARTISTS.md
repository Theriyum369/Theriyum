# Theriyum — Artists



## Purpose



This file will contain structured information about the artists included in Project Theriyum.



## Artist Information



Each artist entry should eventually include:



- Artist name

- Active years

- Genres

- Associated artists

- Influences

- Albums

- Songs

- Musical characteristics

- Era

- Mood

- Notes



## Artist Relationships



Artists should not be treated as isolated entries.



The Theriyum system will connect artists through relationships such as:



- Influenced by

- Influenced

- Collaborated with

- Associated with

- Shared genre

- Shared era

- Shared sound

- Shared musical characteristics
