# Project Theriyum

## Purpose

Project Theriyum is a music library designed to organize, preserve, explore, and understand music through a structured system.

## The Theriyum Theory

The library will be built around the idea that music can be organized not only by artist, genre, or year, but by the relationships between songs, sounds, influences, eras, moods, and musical characteristics.

## Library

The music library will eventually contain structured information about:

- Artists
- Albums
- Songs
- Genres
- Subgenres
- Eras
- Influences
- Musical characteristics
- Connections between recordings

## Project Status

Project Theriyum is currently under construction.
