# Theriyum — Albums

## Purpose

This file records albums, EPs, mixtapes, and other releases and connects them to artists, songs, genres, sounds, eras, and scenes within Project Theriyum.

## Album Information

Each release entry should eventually include:

- Release title
- Artist
- Release type
- Year
- Label
- Genres/styles
- Songs
- Sound characteristics
- Related artists
- Related releases
- Era
- Scene or culture
- Theriyum notes
